Introducción

El presente documento corresponde al desarrollo académico de la Actividad N.° 7 de Aplicaciones Web 1. Para esta etapa se recibió y revisó el sitio de fotografía profesional de Lucía Fernández realizado por una compañera, y luego se incorporaron los nuevos requisitos de CSS sobre esa base.

El sitio conserva las páginas de presentación y contacto, junto con la identidad visual y los recursos originales del proyecto recibido.

2. Trabajo recibido

Persona de quien se recibió el trabajo: Zaira Di Fini.

La entrega presenta a Lucía Fernández como fotógrafa independiente especializada en retratos, eventos y fotografía para emprendimientos. Incluye una página de presentación de servicios y trayectoria, y otra con un formulario de contacto para consultas y presupuestos.

 

3. Revisión y correcciones realizadas

Durante la revisión del proyecto recibido se detectaron los siguientes detalles técnicos y se corrigieron en la copia de trabajo de la Actividad 7:

  • Las páginas referenciaban la carpeta recursos/ en minúsculas, pero la carpeta entregada se llama Recursos/. En Linux la diferencia de mayúsculas y minúsculas impedía cargar las hojas de estilo y la imagen. Se actualizaron los enlaces para que coincidan con el nombre real.
  • La imagen del encabezado tenía height: 90x, una unidad inválida. Se corrigió a 90px.
  • La página de contacto declaraba lang="en" aunque su contenido está en español. Se corrigió a lang="es".
  • Se normalizó el enlace externo de Instagram y se agregó rel="noopener noreferrer" a los enlaces que abren una pestaña nueva.

 

4. Requisitos de la Actividad 7

Los cambios se aplicaron sobre la identidad y el contenido del proyecto recibido, manteniendo el reset, los selectores de tipo, las clases principales, el modelo de caja alternativo y la tipografía Outfit.

4.1. Encabezado flexible y sticky

El encabezado utiliza display: flex para distribuir el logotipo y la navegación. Se mantiene visible durante el desplazamiento con position: sticky y top: 0. Los enlaces de navegación permanecen visibles tanto en escritorio como en móvil, donde pueden ajustarse a más de una línea sin JavaScript (Senn, 2023, pp. 167–172, 179–180).

4.2. Grilla del layout

La página de inicio separa presentación, servicios y trayectoria en bloques visuales; cada tipo de servicio tiene su propio panel. El formulario organiza los campos en los grupos “Tus datos” y “Detalles del trabajo”. En pantallas angostas las grillas pasan a una columna. Para CSS Grid y el espaciado gap, que no se desarrollan en el material de estudio, se consultó MDN Web Docs.

4.3. Identidad visual, mensajería y favicon

El encabezado y el pie de página usan blanco (#ffffff) sobre un fondo gris verdoso claro (#f1f4f3); el texto es tinta oscura (#24323a) y el terracota (#c85b46) destaca las acciones. El enlace fijo de WhatsApp es un botón circular color terracota, solo con icono y con nombre accesible para lectores de pantalla. Se utilizó border-radius para redondearlo y SVG en línea para el pictograma (MDN Web Docs). No se asignó un número de destino porque no se proporcionó uno. El favicon reutiliza el ícono fotográfico local (Senn, 2023, pp. 76–77, 179–180). La fuente Outfit se conserva con @font-face (MDN Web Docs).

4.4. Galería de referencias visuales

La galería presenta ejemplos ilustrativos de retrato, eventos y fotografía de productos. No se atribuyen a Lucía Fernández; cada imagen muestra en la página su autoría, licencia y enlace a la fuente original.

 

5. Verificación técnica

  • Five Server se inicia desde el proyecto con pnpm dev.
  • Las dos páginas, las tres hojas CSS, la fuente y el favicon cargan desde la estructura original src/Recursos/.
  • Se verificó el encabezado flexible y sticky, la grilla de escritorio, el paso a una columna en móvil y el vínculo flotante.
  • La navegación permanece visible en escritorio y móvil; no se incluye JavaScript. Las tres imágenes de la galería cargan y no presentan desbordamiento en móvil.
  • El lockfile de pnpm está sincronizado con Five Server 0.5.0.
